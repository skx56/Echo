# Saksham Ojha — Portfolio

Personal portfolio site for **Saksham Ojha** (IIT Roorkee), matching the design language of [genosis18m.github.io](https://genosis18m.github.io/) with personalized content.

## Stack

- Next.js (static export)
- TypeScript
- Tailwind CSS
- Framer Motion

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build / GitHub Pages

```bash
npm run build
```

Static output lands in `out/`. Deploy that folder (or wire GitHub Actions) to `skx56.github.io`.

## Customize

- Resume: `public/SakshamOjha_Resume.pdf`
- Avatar: `public/avatar.jpg`
- Content: `components/*Section.tsx`, `components/ProfileCard.tsx`, `components/HeroPaint.tsx`
